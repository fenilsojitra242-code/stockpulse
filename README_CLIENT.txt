======================================================================
              STOCKPULSE — QUICK START GUIDE (FOR CLIENT)
======================================================================

Hello! Follow these 3 simple steps to run StockPulse on your computer:

----------------------------------------------------------------------
STEP 1: EXTRACT THE ZIP FILE
----------------------------------------------------------------------
Right-click the ZIP file you received and select:
  -> "Extract All..."
  -> Choose a folder (like your Desktop) and click "Extract".

(IMPORTANT: Make sure you run the app from inside the extracted folder, 
not from directly inside the .zip file preview!)


----------------------------------------------------------------------
STEP 2: RUN THE APPLICATION
----------------------------------------------------------------------
Inside the extracted folder:

  >> For WINDOWS users:
     Just DOUBLE-CLICK the file named:
     "START.bat"

  >> For MAC users:
     Just DOUBLE-CLICK:
     "START.command"

That is all! You do NOT need to type any code or configure anything.


----------------------------------------------------------------------
WHAT WILL HAPPEN AUTOMATICALLY:
----------------------------------------------------------------------
1. The launcher checks if your computer has Python installed.
   (If you don't have Python, it will install it automatically for you).
2. It sets up an isolated environment and installs all needed packages.
   (First-time setup takes 1 to 2 minutes depending on your internet speed).
3. The server starts and AUTOMATICALLY OPENS your default web browser 
   (Chrome, Edge, Safari, etc.) directly to the StockPulse Dashboard:
   http://127.0.0.1:8000

4. Next time you click "START.bat", it opens instantly in 2 seconds!


----------------------------------------------------------------------
HOW TO STOP THE APPLICATION:
----------------------------------------------------------------------
- Simply close the black terminal window, or press [Ctrl + C].
- Alternatively, on Windows you can double-click "STOP.bat".


----------------------------------------------------------------------
NEED HELP OR HAVE QUESTIONS?
----------------------------------------------------------------------
If you see any prompts from Windows Firewall, click "Allow access".
For any assistance, please contact your project developer.
